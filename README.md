# repofacts

Deterministic shared knowledge map of a repository's codebase for AI agents and coding sessions.

Automatically build a reliable, structured, evidence-backed, versioned profile of your codebase - its architecture, interfaces, dependencies and history.

Facts about code, not guesses.
One source of truth for every coding agent.
Agents start fast with the same verified context, across sessions and models.

## Overview

`repofacts` builds a deterministic structural map of a repository so that new AI agents and sessions do not have to rediscover the codebase from scratch:

- Existing modules and boundaries
- Public interfaces
- Inter-module dependencies
- Tests linked to specific components
- API endpoints and related authorization mechanisms

*Status: Early development / placeholder release (`0.0.1`).*
